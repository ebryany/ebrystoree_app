# Ebrystore API Threat Model

Analisis ancaman berbasis arsitektur aktual Ebrystore (TanStack Start + Vite SSR + Supabase Auth/PostgreSQL/RLS/Storage + Cloudflare + Nginx).

| ID Ancaman | Vektor Serangan | Aset / Target | Mitigasi Berlapis (Defense in Depth) | Deteksi & Alert |
|---|---|---|---|---|
| **T-01** | Direct endpoint invocation (`/_serverFn/*` atau `/api/*`) hanya dengan bermodal URL | Data order, profil user, katalog draf, kontrol admin | `requireSupabaseAuth` memverifikasi Bearer JWT + `assertPermission()` di setiap fungsi + Supabase RLS | Event `forbidden_permission_access` / `unauthenticated` tercatat; Alert `BRUTE_FORCE_ADMIN_PROBE` (>= 5x / 5m) |
| **T-02** | Privilege escalation via Supabase PostgREST atau MCP (`POST /rest/v1/user_roles`, `/rest/v1/role_permissions`, `manage_user_role`) | Promosi akun biasa/admin menjadi `super_admin` atau pemberian izin keuangan/SMTP | Trigger `protect_role_changes()` memblokir `super_admin` dari non-`super_admin`; trigger `protect_role_permissions_changes()` & RLS `is_super_admin()` pada `permissions`/`role_permissions`; validasi ulang di MCP `manage_user_role` | Event `privilege_escalation_attempt` (`CRITICAL`) memicu alert `PRIVILEGE_ESCALATION_ATTEMPT` seketika (threshold 1) |
| **T-03** | IDOR & Horizontal Access pada Order, Chat Inquiry, PO Custom, Entitlement Produk | Pesanan & file milik pembeli/seller lain | Ownership predicate (`user_id = auth.uid()`), `my_store_id()`, verifikasi di `setInquiryStatus` + RPC SECURITY DEFINER yang memeriksa pemanggil | Event `ownership_violation_attempt`; Alert `IDOR_ENUMERATION_BURST` (>= 8x / 5m) |
| **T-04** | Pemalsuan Callback/Webhook Pembayaran & Cron Internal (`/api/public/payments/webhook/*`, `/api/public/jobs/*`) | Pelunasan pesanan/top-up palsu atau pencurian link kode digital | Verifikasi signature asimetris/HMAC (`shopeepay`, `sumopod`), timing-safe token (`JOBS_CRON_TOKEN`, `JIOFARM_INGEST_TOKEN`), re-query status langsung ke API provider sebelum settle | Event `invalid_webhook_signature` / `invalid_internal_job_token`; Alert `WEBHOOK_SIGNATURE_TAMPERING` (>= 3x / 10m) |
| **T-05** | penyalahgunaan endpoint mahal & Open Email Relay (`sendTestEmail`, `runSeoAuditNow`, `/api/v1/catalog/*`) | Spam email dari domain Ebrystore, SSRF/CPU exhaustion, DB scrape | Permission `settings.manage` untuk email & `settings.seo.update` untuk audit SEO; atomik rate limiter (`email.test`, `seo.audit`, `catalog.public`, bucket finansial fail-closed) + Cloudflare/Nginx | Event `rate_limit_exceeded`; Alert `RATE_LIMIT_ABUSE_SPIKE` (>= 5x / 10m) |
| **T-06** | Information Leakage pada Error UI & Reconnaissance oleh penyerang | Nama permission internal, stack trace DB, email PII | Hapus nama permission (`admin.dashboard.view`, `{permission}`) dari UI/DOM/JSON publik; gunakan branded error pages 401/403/404/429 dengan Request Reference ID | Telemetry `reportUnauthorizedRouteAccess` ketika pengguna non-admin mengakses `/admin/*` atau `/see/*` |
| **T-07** | Log Flooding & Credential Leakage di Audit/Security Log | Penuhnya disk/DB oleh attacker atau bocornya token/cookie di log | Deduplikasi 5 menit via `dedup_key` & `occurrence_count`; `sanitizeSecurityMetadata()` wajib redact key sensitif dan masking email | Indeks waktu & RPC `cleanup_old_security_events(_retention_days)` |
