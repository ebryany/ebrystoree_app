# Diferensiasi Merek Ebrystore

Ebrystore memakai identitas sendiri:
- Logo tas belanja Ebrystore dengan sudut membulat terukur (bukan bentuk lingkaran hijau khas merek lain).
- Palet dasar ink teal gelap netral, bukan hijau merek transportasi.
- Ikon: lucide dengan stroke seragam 1.75; ikon kategori disusun sendiri sesuai kategori Ebrystore (produk digital, desain, editing, setup teknis, tugas digital).
- Tipografi: Space Grotesk + Plus Jakarta Sans.
- Card Ebrystore: radius 12–16px, border tipis, elevasi rendah — bukan kartu kapsul.
- Copywriting: bahasa Indonesia santai-profesional, tanpa slogan/istilah merek lain.
