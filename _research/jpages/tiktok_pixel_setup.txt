# How to Set Up and Verify TikTok Web Data Connection

 Last updated: June 2026 

TikTok for Business offers tools that allow businesses to share marketing data with TikTok for measurement and ad performance. These data connections can be setup for web via a TikTok Pixel or Events API integration.

  

Both options are available via selected third party partners or through a manual setup.

*   **TikTok Pixel** is a piece of code that you can place on your website that allows you to share website events with TikTok. Learn more [about TikTok Pixel](https://ads.tiktok.com/help/article/tiktok-pixel).

*   **TikTok Events API** provides advertisers with a reliable connection between TikTok and advertiser's marketing data, across web, app, and offline (eg. Store, CRM) channels with the ability to customize the information they share with TikTok. Learn more about [Events API](https://ads.tiktok.com/help/article/events-api?lang=en)

  

## How to set up TikTok Data Connection

To set up TikTok Pixel:

1.   Log in to TikTok Ads Manager and go to Tools.

2.   Click **Events Manager**to enter [TikTok Events Manager](https://ads.tiktok.com/help/article/about-tiktok-events-manager).

3.   Click Connect Data Source.

4.   Select Web.

5.   Input your URL.

6.   Select **Partner Integration** or **Manual Setup** as your connection method.

Learn more about [TikTok Events Manager](https://ads.tiktok.com/help/article/about-tiktok-events-manager).

**Note**: If you select Partner Setup, you will be directed to a page where you can select different supported TikTok partners for your integration, [like Shopify and Google Tag Manager](https://ads.tiktok.com/help/article/partner-integrations-for-web-tracking?lang=en).

  

#### For Partner Integrations

1.   Select your preferred third party partner for your data connection

2.   Create and name your pixel. All the events sent to this Pixel Code will show up under this Pixel. We recommend creating a pixel name that corresponds to your website or domain name. The maximum character length is 128 characters, including spaces

3.   Follow steps outlined for the partner within the setup flow

  

#### For Manual Setup

1.   Select your preferred manual connection method*

2.   Create and name your pixel. All the events sent to this Pixel Code will show up under this Pixel. We recommend creating a pixel name that corresponds to your website or domain name. The maximum character length is 128 characters, including spaces

3.   Install the base code onto your website

4.   Manage configurations and desired settings

5.   Follow steps outlined within the setup guide to configure your events. Learn more about [Event Builder](https://ads.tiktok.com/help/article/create-events?lang=en)

  

**Note**: We recommend setting up both the TikTok Pixel and Events API together to maximize measurement and performance of your campaigns

  

We recommend setting up all events throughout the user journey to maximize measurement and optimization opportunities for your campaign

  

### Verify your set up

There are three ways to verify pixel and events set up:

1.   Download [TikTok Pixel Helper](https://chrome.google.com/webstore/detail/tiktok-pixel-helper/aelgobmabdmlfmiblddjfnjodalhidnn?hl=en)) in the Chrome Store and check for any errors. Learn more about Pixel Helper on the [TikTok Pixel Helper page](https://ads.tiktok.com/help/article/tiktok-pixel-helper-2.0?lang=en).

2.   Test pixel events with the Test Events feature in Events manager. Learn more about [Test Events](https://ads.tiktok.com/help/article/test-tiktok-pixel-events-video-walkthrough?lang=en).

3.   Use the Diagnostics tab in Events Manager to resolve any issues presented. Learn more about [Web Diagnostics](https://ads.tiktok.com/help/article/web-diagnostics?lang=en).
